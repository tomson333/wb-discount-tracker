LEGAL & TECH NOTES
- This project uses Wildberries public catalog endpoints. Respect their terms of use and rate limits.
- For production use, implement caching, retries, and respect robots/TOS.
- To get a downloadable APK automatically, push this repo to GitHub and enable Actions; the workflow will build a debug APK and upload it as an artifact.
- Alternatively, build locally with Android Studio or using the included Dockerfile.
